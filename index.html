Cloud Sync & Database Backups
Realtime Cloud Synchronisatie

Om alle trainingen en intekeningen live te synchroniseren tussen alle smartphones via GitHub Pages, kun je hier een gratis Firebase Realtime Database URL of JSON endpoint koppelen.

Laat leeg voor zuiver lokale offline opslag op dit apparaat.
Hoe maak je deze gratis link in 2 minuten?
  1. Ga naar console.firebase.google.com (gratis inloggen met je Google account).
  2. Klik op "Project toevoegen" → geef het de naam dodentocht-team → klik op Doorgaan/Maken.
  3. Kies in het linkermenu onder Build / Maken voor "Realtime Database".
  4. Klik op "Database maken", kies locatie België / Europa (europe-west1).
  5. Kies bij Beveiligingsregels voor "Starten in testmodus" → klik op Inschakelen.
  6. Kopieer de URL die bovenaan verschijnt (begint met https://...firebasedatabase.app) en plak hem hierboven!
